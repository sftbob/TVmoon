# 繁簡片名搜尋

## 使用方式

直接在搜尋欄輸入繁體片名，例如「龍貓」、「魔髮奇緣」；網站會保留輸入文字，同時向片源查詢原文與簡體版本。無須切換語言或額外設定。

搜尋結果保留片源原始片名。相同片源及影片 ID 只顯示一次；繁簡同名、年份與影片類型相同的結果可以合併為同一片卡。播放頁選擇其他來源時，也會以繁簡一致的片名進行比對。

這是字形轉換，不是翻譯或別名服務，例如「動物方城市」與「疯狂动物城」不會因此自動視為同一片名。查無結果時可改用另一個地區的片名，或確認片源是否收錄。

## 實作與維護

- `src/lib/search-text.ts` 使用固定版本 `opencc-js` 的 `t2cn` 子套件；採 `tw → cn` 字形轉換，避免載入完整雙向字典。不呼叫外部翻譯服務。
- `getSearchQueries` 清理前後與重複空白，再將原文及簡體版本去重。簡體與英文若沒有變化，只查一次；空白輸入不查詢。
- `src/lib/downstream.ts` 的 `searchFromApi` 並行查詢最多兩組關鍵字，使用 `[source, id]` 去重。分頁上限、片源逾時與成人內容篩選沿用原設定。
- `normalizeSearchTitle` 僅供片名聚合、排序、精確搜尋及播放換源比對；不得用來改寫影片 ID、來源 ID、媒體網址、使用者輸入或搜尋歷史。
- 繁簡查詢都會等待各自結果；較慢的片源仍可能影響搜尋時間。兩組查詢可能使片源請求量增加，不能宣稱一定加速。
- TypeScript 4.9 的套件型別相容宣告位於 `src/types/opencc-t2cn.d.ts`；Jest 27 的 CommonJS 子套件對應位於 `jest.config.js`。升級工具鏈時應重新檢查是否仍有必要。

## 檢查與驗收

執行 `pnpm test --runInBand`、`pnpm lint`、`pnpm typecheck`、`pnpm build`。相關測試為 `tests/chinese-search.test.js` 與 `tests/search-ui.test.js`。

預覽驗收步驟：

1. 分別搜尋「龍貓」與「龙猫」，確認繁體輸入可以取得簡體片名結果，搜尋欄仍保留原文。
2. 測試「臺灣」與繁簡混合關鍵字，以及英文／數字片名。
3. 在聚合模式確認繁簡同名影片合為片卡，年份或續集不同的影片保持分開。
4. 開啟影片並確認其他播放來源能對應繁簡片名；年份及電影／影集條件仍有效。
5. 留意未回覆或沒有收錄的片源；自動測試使用模擬片源，不代表所有真實片源可用。

正式網址為 `https://tv-moon-lime.vercel.app`。本功能需先經 PR 預覽與使用者驗收，再另行核准合併至 `main`。
