# 影片下載與 PWA 預覽檢查

## 影片檔與串流

- 播放頁標題下方提供「複製播放網址」，網址會跟隨目前集數與播放來源。
- 可辨識的 MP4、WebM、M4V、MOV 另外提供「下載／開啟影片檔」。跨站來源是否下載取決於來源回應與瀏覽器；若另開播放器，可使用瀏覽器另存。
- M3U8 或無法辨識的格式只提供複製網址，交由支援串流的下载工具處理。本版不在網站合併片段、不把整部影片載入瀏覽器記憶體，也不透過 Vercel 轉送影片檔。
- 複製權限不可用時提供可選取的網址。請勿將含存取權杖的播放網址貼到公開處。

## 安裝

- 使用者選單中的「安裝 App」會在支援的瀏覽器觸發安裝提示；尚未提供提示時顯示操作引導。
- iPhone／iPad：Safari 的分享選單 → 加入主畫面。
- Android／電腦：Chrome 或 Edge 的安裝／加入主畫面選單。
- 名稱沿用部署的 `SITE_NAME`，使用既有圖示；已在獨立 App 視窗中不再顯示安裝入口。
- API 與登入後頁面採用網路請求，不新增離線觀看。搜尋、登入和串流播放都需要網路。

## 合併前檢查

- 在 HTTPS 預覽站確認一般使用者能開啟安裝引導。
- 用可直接儲存的來源檢查影片檔入口；用串流來源確認只提供複製網址。
- 切換集數、換源後確認網址更新，複製成功訊息不沿用舊來源。
- Android Chrome／iPhone Safari 的實際安裝需要在對應裝置測試，桌面測試無法代替。
