# PWA 與播放介面預覽檢查

- 選單保留「安裝 App」，支援的瀏覽器提供安裝提示，其餘顯示平台操作說明。
- 已安裝並使用獨立 App 視窗時隱藏安裝入口。
- 搜尋、登入與播放需要網路，不提供離線影片。
- 播放頁移除下載、複製媒體網址、待下載清單與插件交接入口。
- 不再查詢插件、取得下載用網址或送出下載任務。

## 預覽驗收

- 確認播放、換集、換源、搜尋與觀看記錄正常。
- 確認播放頁不再顯示下載相關介面。
- 確認選單的安裝提示與平台說明正常。
- Windows／Android Chrome 或 Edge、iPhone Safari 的實際安裝需要對應裝置驗證。

正式站須待使用者驗收再合併。後續優化優先處理海報速度，再處理播放操作與手機版面。
