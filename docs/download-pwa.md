# 影片下載與 PWA 預覽檢查

## 影片檔與串流

- 播放頁標題下方提供「複製播放網址」，網址會跟隨目前集數與播放來源。
- 可辨識的 MP4、WebM、M4V、MOV 另外提供「下載／開啟影片檔」。跨站來源是否下載取決於來源回應與瀏覽器；若另開播放器，可使用瀏覽器另存。
- M3U8 可加入批量待下載清單，由 Windows 助手交給 yt-dlp／FFmpeg 下載及合併，不透過 Vercel 轉送影片。
- 複製權限不可用時提供可選取的網址。請勿將含存取權杖的播放網址貼到公開處。

## 安裝

- 使用者選單中的「安裝 App」會在支援的瀏覽器觸發安裝提示；尚未提供提示時顯示操作引導。
- iPhone／iPad：Safari 的分享選單 → 加入主畫面。
- Android／電腦：Chrome 或 Edge 的安裝／加入主畫面選單。
- 名稱沿用部署的 `SITE_NAME`，使用既有圖示；已在獨立 App 視窗中不再顯示安裝入口。
- API 與登入後頁面採用網路請求，不新增離線觀看。搜尋、登入和串流播放都需要網路。

## 合併前檢查

- 在 HTTPS 預覽站確認一般使用者能開啟安裝引導。
- 用可直接儲存的來源檢查影片檔入口；用串流來源確認批量加入、匯出與本機下載。
- 切換集數、換源後確認網址更新，複製成功訊息不沿用舊來源。
- Android Chrome／iPhone Safari 的實際安裝需要在對應裝置測試，桌面測試無法代替。

## Windows 批量下載

- 播放頁可全選／逐集勾選，跨影片累積待下載清單、批量移除及匯出勾選任務。
- 清單依網站帳號分開保存於瀏覽器；網址可能含短期存取資訊，請勿分享任務檔。同來源同集數重新加入會更新網址，最多 500 集。
- 同時下載數 1–3、片段連線數 1／2／4／8，預設 2 部 × 4 條。網站保留設定，但不接收本機進度。
- 下載 Windows 助手 ZIP，依內附 README.txt 一次設定 yt-dlp、FFmpeg；可選 aria2c 支援 HTTP 檔案分段。啟動 Start-TVmoon.cmd 後選擇任務檔即可自動處理。
- 片段並行以來源支援為前提；缺失片段視為失敗，避免將缺片影片標示完成。一般檔案無 aria2c 時用單連線。
- 電腦直接接收影片，網站可關閉；助手與電腦需持續執行。結果與各影片 log 保存在 Downloads；失敗任務另存可重試清單。重新执行相同任務可續傳／略過完成檔案。
- 來源過期、限速、需要特殊驗證、直播或 DRM 來源未保證可下載。此版本未啟動本機網路服務、沒有一鍵遠端啟動或網站即時進度。
- Windows 助手以模擬下載器驗證排程、完成／失敗狀態、重試清單及參數安全；真實來源速度與 FFmpeg 合併仍需安裝工具後測試。
